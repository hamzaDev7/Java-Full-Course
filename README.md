HamzaTech Java Course

Welcome to the HamzaTech Java Course repository. This repo contains lecture-by-lecture Java code examples and demos used throughout the course.

## Course Structure

- Each lecture has its own folder (e.g., `Lecture 03/`).
- Most lectures include a `code/` folder with Java demo files (e.g., `Demo.java`, `Demo2.java`).
- Some lectures include additional subfolders for package examples (e.g., `school/`, `college/`).

## How to Use

1. Open any lecture folder.
2. Go to the `code/` directory.
3. Open the `Demo.java` (or related) files in your IDE.
4. Compile and run the examples to follow along with the lesson.

Example (PowerShell):

```powershell
cd "Lecture 05\code"
javac Demo.java
java Demo
```

## Prerequisites

- Java Development Kit (JDK) 17 or later
- A Java-friendly IDE (VS Code, IntelliJ IDEA, Eclipse) or terminal tools

## Course Outline

- Fundamentals: variables, data types, operators
- Control flow: conditionals and loops
- Methods and recursion
- Object-oriented programming
- Collections and generics
- Exception handling
- Packages and access modifiers
- File I/O basics

## Learning Outcomes

- Write and run Java programs confidently
- Apply OOP concepts to model real problems
- Debug common errors using IDE tools
- Organize code using packages and classes
